# File Organizer Agent

Organizes files in a directory into category subfolders by type.

## Categories

- Documents: pdf, txt, md, rtf, epub, doc, docx, xls, xlsx, ppt, pptx
- Images: jpg, jpeg, png, gif, webp, svg, heic
- Videos: mp4, mkv, mov, avi, webm
- Music: mp3, flac, wav, m4a, ogg
- Archives: zip, tar, gz, rar, 7z
- Misc: everything else

## Usage

```bash
aichat --agent file-organizer "Organize files in the current directory by type"
aichat --agent file-organizer "Organize my Downloads folder"
